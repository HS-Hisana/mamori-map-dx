# まもりマップ DX

地域の危険な場所をみんなで共有する、参加型の安全マップです。
お年寄り・こども・外国人が「画面を見ずに歩いても安全」な地域をつくることを目指しています。

- 公開アプリ：https://mamori-map-dx.web.app
- 紹介ページ：https://mamori-map-dx-intro.web.app

岡山芳泉高校 情報Ⅰ 課題研究（作者：緋真）。全国情報教育コンテスト2026の応募作品です。
拠点は岡山芳泉高校周辺（岡山市南区芳泉3-1-1）です。

## できること

- **危険メモの投稿** — 見通しの悪い交差点や暗い夜道など、危ない場所を地図に投稿できます。写真付きで、ぼかしもできます。
- **みんなの一覧** — 他の人の危険メモが見られます。「ありがとう」や改善確認、通報もできます。
- **ポイント・ランク** — 投稿や「ありがとう」でポイントがたまります。見習い隊員からレジェンド守護神（200pt）まで、5つのランクがあります。
- **ポイントランキング** — レジェンド守護神（200pt以上）の上位15人と、自分の順位が見られます。ニックネームの表示・非表示も選べます。
- **安全ルート vs 危険ルート** — 実際の道路に沿った安全なルートと危険なルートを比べて表示します。GPSで追いかけてくれます。
- **見守りモード** — ポケットに入れたまま、危険な場所に近づくと音声と振動でお知らせします。
- **32言語対応** — 日本語・やさしい日本語・世界の主要30言語に対応。起動時に言語を選べます。ふりがなのON/OFFもできます。
- **施設・お店情報** — トイレやゴミ箱の有無、お店の特売が見られます。世界中のお店を探して登録することもできます。
- **渋滞・交通量表示** — 国土交通省の公式データで、車の多さを地図に表示します。
- **警察・消防メモ** — 警察・消防の公式HPの速報を地図のピンでお知らせします。
- **利用状況・感想レポート** — 登録者数やメモ数、都道府県・国ごとの集計、みんなの感想が見られます。CSVで出すこともできます。
- **ログイン** — メールアドレスとパスワード、またはGoogleアカウントでログインできます。

## ファイル構成

```
mamori-map-dx/
  index.html              アプリ本体（単一ファイル、PWA対応）
  manifest.webmanifest    アプリ名・アイコン・起動方法の定義
  sw.js                   Service Worker（オフライン用キャッシュ）
  icons/                  アプリアイコン
  firebase.json           Firebase Hosting の設定
  firestore.rules         Firestore のセキュリティルール
  .firebaserc             Firebase プロジェクトの設定
```

地図は Leaflet + OpenStreetMap を使っています。

## ローカルで動かす

Service Worker を使うため、`file://` で直接開くのではなく、ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 公開する方法（Firebase Hosting）

```bash
firebase deploy --only hosting --project mamori-map-dx
```

公開には Firebase プロジェクトが必要です。このアプリでは次の機能を使っています。

- Authentication：Googleログイン・匿名ログイン
- Cloud Firestore：危険メモとランキングの共有（東京リージョン）
  - `firestore.rules` をデプロイしてください（`firebase deploy --only firestore:rules`）

## 注意

- このリポジトリは公開版（PWA）のコードです。Muse 内で動くライブアプリ版は別にあり、地図の土台やデータの保存先が違うため、アカウントや投稿は共有されません。
- 投稿した危険メモはみんなに公開されます。氏名・住所・電話番号など、個人が特定される情報は書かないでください。
- 写真は端末の中でぼかしてから送られます。ぼかしをONにすると、元の写真は送信・保存されません。
- パスワードは安全な方法で保管され、平文では保存されません。
